REQUEST FOR QUOTATION General Workstation Refresh -- 16" Touchscreen Notebook Computers with Memory Upgrade Clear Creek County, Georgetown, Colorado Issuing Department: Clear Creek County IT Department RFQ Number: RFQ #IT-2026-007 Issue Date: August 20, 2026 Submission Deadline: August 31, 2026 at 5:00 PM MDT Submission Method: Email only -- see Section 5 for instructions Contact / Submit To: For security reasons, you must enable JavaScript to view this E-mail address. Award Basis: Best overall value -- price is one factor among several 1. Purpose and Overview Clear Creek County IT Department is soliciting competitive quotations from qualified vendors for the procurement of 16-inch touchscreen notebook computers and compatible memory upgrade modules as part of a county-wide general workstation refresh. This is an open public request; any qualified vendor may respond. The County is replacing aging workstations across departments with modern, vPro-managed, touchscreen-capable notebooks. Units include a same-day memory upgrade from 16 GB to 32 GB via third-party SODIMM modules. All three line items -- notebook, ProSupport warranty, and memory -- must be quoted together. This RFQ is not a contract or a commitment to purchase. The County reserves the right to accept or reject any or all quotations, to waive any informalities, and to award to the vendor deemed most advantageous to the County. 2. Deployment Context Vendors should understand the intended use when preparing proposals: - County-wide general staff refresh -- multiple departments - Replacing end-of-life workstations with current-generation notebooks - Touchscreen required -- IPS display technology preferred - vPro manageability required for remote IT administration across county network - Memory will be upgraded to 32 GB at deployment using third-party SODIMM modules quoted separately - Wi-Fi 6E required for compatibility with county wireless infrastructure - 4-year ProSupport with Next Business Day Onsite required for IT support consistency - All units must be new; no refurbished or gray-market units 3. Technical Specifications Vendors must quote the exact models specified below, or may propose approved equivalents with full technical documentation attached. Substitutions must be clearly identified with a side-by-side specification comparison. All three line items are required -- partial bids will not be considered. Item 1 -- Dell Pro 16 PC16250 16" Touchscreen Notebook (Qty: 10) Specification Requirement Make / Model Dell Pro 16 PC16250 16" Touchscreen Notebook (or approved equivalent) Processor Intel Core Ultra 7 265U, vPro Technology Memory (Base) 16 GB (to be upgraded to 32 GB at deployment -- see Item 3) Storage 512 GB SSD Display 16" Touchscreen, Full HD Plus, 1920 x 1200, 60 Hz, IPS Technology Operating System Windows 11 Pro Graphics Intel Integrated Camera Front Camera / Webcam Battery 8.70 Hours rated run time Wireless IEEE 802.11ax Wireless LAN Standard (Wi-Fi 6E) Keyboard English (US) Color Platinum Silver, Metallic Quantity 10 units Condition New only -- no refurbished or gray-market units Item 2 -- Dell ProSupport Extended Service, 4-Year NBD Onsite (Qty: 10) Specification Requirement Service Type Dell ProSupport Extended Service Term 4 Years Response Level Next Business Day (NBD) On-site Coverage Hours 10 x 5 (business hours) Coverage Type Maintenance -- Parts & Labor Quantity 10 (one per notebook) Item 3 -- Memory Upgrade: V2 Technologies 16 GB DDR5 SODIMM (Qty: 10) Specification Requirement Make / Model V2 Technologies 16 GB DDR5 2Rx4 SODIMM Non-ECC 5600 MT/s (PC5-44800) (or approved equivalent) Capacity 16 GB per module (brings total system RAM to 32 GB) Type DDR5, 2Rx4, SODIMM, Non-ECC Speed 5600 MT/s (PC5-44800) Compatibility Must be verified compatible with Dell Pro 16 PC16250 (or proposed equivalent notebook) Quantity 10 modules (one per notebook) Pricing Response Format Vendors must provide itemized pricing in the format below.
